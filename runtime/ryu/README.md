# Native shortest decimal formatter

Unmodified C-only subset from [Ryu](https://github.com/ulfjack/ryu/tree/4c0618b0e44f7ef027ebae05d2cc7812048f7c8f), commit `4c0618b0e44f7ef027ebae05d2cc7812048f7c8f`.

The C d2s converter supplies shortest round-trip digits. FreeLang applies the v11/JavaScript fixed/exponent display thresholds separately. No upstream build tools or other implementation languages are included or executed. Boost/Apache license notices are retained. Included from the native runtime using the existing runtime include directory.
