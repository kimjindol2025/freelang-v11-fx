# 실제 편집기 사진 메뉴 브라우저 기준

PRD v0.6 E03의 부분 인수다. 실제 app/main을 새 합성 WAL·세션·검증된 PNG fixture로 실행한다. 운영 자료·실제 계정은 사용하지 않는다. 기존 내장 JS를 무수정으로 실행하며 이를 L01 J안 구현 완료로 보고하지 않는다.

Chrome 전용 새 profile과 자동 포트만 사용한다. native C CDP client가 DOM/CSS·실제 mouse input·화면 캡처를 사용한다. Runtime.evaluate/주입 JS·새 TS/수작업 JS/Python 파일은 없다. Cookie는 환경에서 읽고 값·원문 CDP traffic을 보고하지 않는다. 다른 browser나 process를 종료하지 않는다.

375×812·768×1024·1440×900 각각 시각 편집기 준비, 초기 preview 숨김, 상단 사진 메뉴 열기, 실제 이미지 삽입, alt 보존, 삽입 뒤 비어 있는 preview 숨김, 결과 보기의 이미지 표시, 돌아온 편집기의 이미지 보존, browser exception 0의 9개 판정을 고정한다. 총 27개이며 screenshot PNG도 세 개 보존한다. 실패 원문·실제 종료 코드를 보존하고 UI 수정 전에 정답을 커밋한다.

빈 안내가 남는지 먼저 실제 브라우저에서 확인한다. 실패 원인 확인 없이 CSS/JS를 바꾸지 않는다. 기존 JS 수정은 금지한다. 이 작은 흐름의 통과를 실제 비밀번호 로그인·갤러리·alt/캡션 수정·저장·다시 열기·키보드·자동저장·완전한 E03 인수로 확대하지 않는다.

기본 fixture는 테스트 C가 직접 생성한 320×180 PNG 패턴이다. 외부 decoder/이미지 라이브러리를 추가하지 않으며 원본 보존 hash를 기록한다. 기존 실행은 사전 지정한 합성 PNG도 사용할 수 있다. 실제 사진/제품 처리기 인수 증거로 확대하지 않는다. 여러 폭 사이의 이동은 이 시험이 만든 미저장 초안만 버리고, 다른 종류의 dialog는 실패한다. 기존 app 실행물을 재사용하면 source 기준과 실행물 hash를 기록하며 client는 새로 빌드한다.
