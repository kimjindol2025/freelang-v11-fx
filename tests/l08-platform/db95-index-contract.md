# L05 db95 자체 인덱스 최소 기준

승인된 db95 `88b4aa2ca11e5355240a1d93ece8321315c669cc` 소스만 로드한다. 블로그·app/store·그 보정 함수를 로드하거나 재정의하지 않는다. 새 합성 WAL과 l05_records만 사용한다. 일반 레코드 삽입, 여러 AST의 수정/삭제/재삽입, 실패 batch rollback 후 기본/보조 인덱스의 실제 index-scan 결과와 전체 행 수를 고정 정답과 비교한다. rollback 때 WAL byte hash가 같아야 한다. 이후 별도 과정으로 10회 재시작하고 매번 같은 결과·WAL 불변을 검사한다.

정답·시험을 먼저 커밋한다. 실행 시 DB/fx/시험 커밋·실제 출력·종료 코드를 남기며 ASan/UBSan과 execve 감사는 별도로 보고한다. 이 작은 기준의 통과를 긴 WAL·손상·동시 거래·장애 내구성·L05 전체 완료로 판정하지 않는다. 시험이 실패하면 언어 문제와 DB 문제의 원인을 구분하고 언어/저장소에서 수정한다. 앱 scan 우회로 정답을 맞추지 않는다.
