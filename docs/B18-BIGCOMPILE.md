# B18 큰 앱 컴파일 검수

B18=계속. 전체 앱 C 생성·ELF 링크와 모든 원래 회귀 구성 관문이 통과했다. 현재 기준점에 이미 포함된 수정을 재사용했으며 새 메모리 패치는 추가하지 않았다. 검증 소스는 `81d7e2649041bf9999551301ea0029da394d357d`이며 `fix/b18-bigcompile`을 해당 CLEAN 지점에서 분기했다. 이번 작업에서 언어·런타임 소스 수정은 0개다.

측정 대상은 fl-git `d2dc91d51f4b479b26f3366f012d0deec36ad235`의 FE13에서 사용한 전체 앱 입력이다. 해당 저장소에는 다른 창의 기존 변경 8개가 있었으며 읽기만 했다. 현재 작업 트리에서 새 프론트 빌드를 실행하지 않았다. FE13에서 보존한 전체 입력 315480바이트를 작업 전용 영역으로 읽어 측정했다. 전체 입력 SHA256은 `7f3c1573204f5aaa4db10752c4ee24279fc56b213b2ad79426f240e870324aac`다.

시작 점검에서 폴더·가지·도구 PATH·출력 폴더 쓰기·공유 잠금 상태를 확인했다. 매 무거운 작업 직전 ps를 보존하고 지정된 공통 flock을 차례로 사용했다. 메모리는 2147483648바이트, swap 0, core 0이며 일반 native 빌드에는 주소 공간 2097152KiB도 적용했다. sanitizer는 물리 메모리 제한을 유지했다. 일반 임시 자료와 TMPDIR는 모두 작업 전용 영역 <가림>이다. TLS 원래 관문의 합성 키만 기존 승인 규칙대로 별도 임시 영역 <가림>에 생성 후 삭제했다.

## FE13 실패와 이번 기준점 구분

FE13 원문은 요청 FX 소스 `7f6e830456533226b3d6d67aabbf3f063ee78384`를 다시 빌드하지 않았다고 명시한다. 실제 측정 ELF는 과거 FE-11R Stage3이며 SHA256 `124a9da3db2e6e6f4b9988650b0ae6e5762a9097870d6ad3c44373922448e429`다. 아래 과거 값은 FE13 보존 증거이며 이번에 구형 실행 파일을 재실행한 결과가 아니다.

| FE13 입력 bytes | 초 | 최대 RSS KiB | 결과 |
| ---: | ---: | ---: | --- |
| 77493 | 4.91 | 493168 | C 생성 성공 |
| 154806 | 10.30 | 852912 | C 생성 성공 |
| 315480 | 18.76 | 1945364 | exit 1, lexer/string text allocation failure |

이미 두 번 관측된 구형 실패를 세 번째 반복하지 않았다. B15 `1dd15864807fd438ef77e058dba7ae2841ec51bf`의 `self/cgc-main.fl:128`에는 긴 문자열을 기존 vec-builder에 넣고 한 번 freeze/join하는 수정이 들어 있다. 불변 렉서 key 재사용·기존 map 생성 API 재사용도 당시 반영됐다. B17R `725c679`의 includes-item native 순회 재사용도 현재 출발점에 포함돼 있다. 현재 기준점에서 같은 전체 입력의 실패가 재현되지 않았으므로 같은 최적화를 다시 구현하지 않았다.

## 실행 중 운영체제 재부팅

초기 전체 회귀는 SMALL_LEAKS·WORKER 및 E07의 CLI·Chrome 6개·CLI 옵션·CLOCK·L07·누수 사전 5그룹까지 종료 0을 기록했다. 이후 운영체제가 재부팅됐다. 재접속 때 uptime이 2분이었고 이전 transient 실행 단위가 사라졌으며, 해당 단위·E08 driver의 최종 종료 기록은 없었다. 타이머 sanitizer는 앞의 세 사례 종료 0까지만 기록돼 있었다. 이를 컴파일러 실패나 전체 회귀 통과로 바꾸어 쓰지 않았다.

완료된 상위 관문 17개는 원문 결과를 유지했다. 미완료 타이머 5개 묶음만 새 결과 영역에서 원래 러너로 다시 실행했다. 기존 러너에는 중간 재개 선택기가 없어 앞의 세 하위 사례도 그 묶음 안에서 다시 실행되며, 최초 원문은 보존한다. 이어 미실행이었던 NATIVE_ALL을 원래 러너로 실행했다. 시험·기대값·제한시간·러너 파일 수정은 0이다. 일괄 E08 driver의 재부팅 중단과 구성 관문의 최종 완료 여부를 따로 기록한다.

중간 이력 조회에서 작성자 메타데이터를 한 차례 가리지 못했다. 이후 작성자 필드를 제외한 이력 조회와 출력 가림 필터를 사용했으며, 해당 원문은 보고서·커밋에 포함하지 않는다. 커밋할 diff의 민감정보 검사를 별도로 수행해 PASS를 확인했다.

FE13 보존 실패 원문을 재실행 없이 직접 확인했다. B15에서 교체한 문자열 누적 함수와 실제 실패 스택이 일치한다.

기존 시험·기대값·제한시간·러너·PRD·seed와 언어/런타임 소스 diff는0이다. 임시 조정 파일은 결과 영역·환경·재시작 후 미완료 관문의 실행만 지정했다. Git에 남기는 변경은 이 문서1개다. 커밋 전 전체 staged diff에서 경로·작성자·주소·키·토큰·비밀번호를 확인했고 민감정보 검사 PASS였다. GitHub만 푸시하고 Forgejo는 보류한다. 보고서 자신의 최종 커밋 HEAD·원격 일치·CLEAN은 커밋 후 완료 응답에 기록한다.
