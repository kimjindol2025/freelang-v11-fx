FreeLang v11은 Lisp 계열의 간결한 문법과 C 네이티브 런타임을 결합한 언어입니다. 검증된 Native C Stage 0에서 시작해 자기 compiler를 다시 만들고, 같은 결과로 수렴합니다.

FreeLang은 무엇인가?

작은 언어 실험이 아니라, 실제 서비스와 네이티브 실행 파일을 향해 성장하는 언어 생태계입니다.

01

간결한 표현

Lisp 스타일의 표현식과 명시적인 데이터 구조로 컴파일러와 도메인 로직을 읽기 쉽게 표현합니다.

02

C 네이티브 실행

FreeLang 소스를 C로 변환하고 시스템 compiler로 단일 ELF 실행 파일을 만듭니다.

03

자기 재생성

compiler가 자기 소스를 다시 컴파일하며 생성 결과의 고정점을 자동 검증합니다.
